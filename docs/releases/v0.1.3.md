# SketchFrame 0.1.3

## 변경 사항

- 파란색 배경과 흰색 스케치 드래그 심볼의 앱 아이콘을 추가했습니다. Finder와 앱 권한 안내 등에서 SketchFrame을 구분할 수 있습니다.
- README의 설치·업데이트 안내를 정리하고, 업데이트 확인 주기를 설명하는 문장을 제거했습니다. 앱의 업데이트 동작은 유지합니다.

## 설치와 업데이트

Apple Silicon, macOS 13 이상을 지원합니다. 기존 사용자는 앱의 **업데이트 확인…**에서 새 버전을 설치할 수 있습니다. 단축키 설정과 기존 서명 인증서를 유지합니다.

Homebrew가 설치되어 있다면 다음 명령으로 설치할 수 있습니다.

```sh
brew install --cask mozzi-papa/tap/sketchframe
```

Homebrew로 설치한 앱은 다음 명령으로 업데이트할 수 있습니다.

```sh
brew update
brew upgrade --cask --greedy mozzi-papa/tap/sketchframe
```

수동 설치는 ZIP과 `.sha256` 파일을 내려받아 체크섬을 확인한 뒤 `SketchFrame.app`을 응용 프로그램 폴더로 옮겨 주세요. 처음 실행할 때 시스템 설정의 손쉬운 사용 권한을 허용해야 합니다.

버전은 0.1.3, 빌드는 4입니다. 기존과 같은 로컬 인증서로 서명합니다. Apple Developer ID 서명·공증은 포함하지 않으므로 다른 Mac에서 실행이 차단될 수 있습니다.
