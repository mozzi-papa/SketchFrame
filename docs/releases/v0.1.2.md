# SketchFrame 0.1.2

## 변경 사항

- 오른쪽 절반에 배치한 창에서 같은 단축키를 다시 누르면 오른쪽 모니터의 왼쪽 절반으로 이동합니다. 왼쪽 절반도 반대 방향으로 동작합니다.
- 옆 모니터로 이동한 뒤 같은 단축키를 누르면 해당 모니터의 반대쪽 절반으로 이동합니다. 해당 방향에 모니터가 없으면 현재 절반을 유지합니다.
- 모니터의 실제 배치 방향과 작업 영역·배율을 반영합니다. 위아래로만 배치되거나 모서리만 닿는 모니터는 좌우 이동 대상에서 제외합니다.
- 키보드 배치는 기존처럼 크기 지원 검사와 적용 후 대기·경고 오버레이 없이 바로 요청합니다.
- 이전 공개 버전 0.1.0 이후 변경한 스케치 드래그 모양의 메뉴 막대 아이콘을 포함합니다.

앱이 최소 크기 제한으로 반쪽 크기를 지원하지 않으면 반복 이동이 인식되지 않을 수 있습니다.

## 설치와 업데이트

Apple Silicon, macOS 13 이상을 지원합니다. 기존 앱의 **업데이트 확인…**에서 설치하거나 ZIP과 `.sha256` 파일을 내려받아 체크섬을 확인한 뒤 `SketchFrame.app`을 실행해 주세요. Rectangle과 기본 단축키가 겹치므로 한쪽을 종료하거나 키를 변경해 주세요.

버전은 0.1.2, 빌드는 3입니다. 기존과 같은 로컬 인증서로 서명하며 단축키 설정을 유지합니다. Apple Developer ID 서명·공증은 포함하지 않으므로 다른 Mac에서 실행이 차단될 수 있습니다.
