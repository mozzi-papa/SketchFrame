# SketchFrame 0.1.4

## 변경 사항

- 메뉴의 마지막 창 배치 결과 행을 제거하고, **자유 영역 그리기 · ON/OFF**로 토글의 대상을 명확히 했습니다. 사용 가능한 ON 상태는 초록색 도트, OFF는 회색 도트로 표시합니다.
- 자유 영역 그리기를 꺼도 키보드 창 배치와 입력 연결을 유지합니다. 마지막 배치 결과는 메뉴 막대 아이콘의 도움말에서 확인할 수 있습니다.
- 화면 잠금·절전·사용자 세션 전환 시 이전 제스처와 키 입력 상태를 정리하고, 복귀 알림을 받으면 입력 연결과 활성 창 조회를 바로 시작하도록 보완했습니다. 잠금 복귀 시 그리기 ON/OFF 상태를 유지합니다.
- 대상 변경이나 창 조회 오류가 나면 오래된 창 정보를 폐기하고 재조회합니다. 실패한 요청을 다른 창에 자동 적용하지 않습니다.
- 대기 중인 이전 창 조회 작업을 취소하고, 복귀 전 작업의 늦은 결과가 새 안내를 덮어쓰지 않도록 보완했습니다.
- 진단 도움말에 복귀 원인·복구 시간·활성 창 추적·작업 대기 상태를 추가했습니다.

## 설치와 업데이트

Apple Silicon, macOS 13 이상을 지원합니다. 기존 사용자는 앱의 **업데이트 확인…**에서 설치할 수 있습니다. 단축키 설정과 기존 서명 인증서를 유지합니다.

```sh
brew install --cask mozzi-papa/tap/sketchframe
```

Homebrew로 설치한 앱은 다음 명령으로 업데이트할 수 있습니다.

```sh
brew update
brew upgrade --cask --greedy mozzi-papa/tap/sketchframe
```

수동 설치는 ZIP과 `.sha256` 파일을 내려받아 체크섬을 확인한 뒤 `SketchFrame.app`을 응용 프로그램 폴더로 옮겨 주세요. 처음 실행할 때 손쉬운 사용 권한을 허용해야 합니다.

## 검증 범위와 제한

자체 검사 280개와 활성 창 캐시 무효화·새 참조 보호·대기 작업 취소 회귀 검사를 수행했습니다. 실제 키보드·마우스 입력, 화면 잠금·인증 후 해제, Homebrew 설치는 이번 버전에서 직접 검증하지 않았습니다. 잠금 보조 알림과 상태 키는 macOS의 공개 계약이 아니므로 OS 변경 시 재검증이 필요합니다.

버전은 0.1.4, 빌드는 5입니다. 로컬 인증서로 서명하며 Apple Developer ID 서명·공증은 포함하지 않습니다. 다른 Mac에서는 실행이 차단될 수 있습니다.
