# SketchFrame 0.1.0

Mac의 활성 창을 단축키로 배치하거나 직접 그린 영역으로 이동·크기 조절하는 메뉴 막대 앱입니다.

- Command + Shift + 왼쪽 드래그로 자유 영역을 지정합니다. 단축키는 설정에서 변경할 수 있습니다.
- 반쪽·모서리·최대화·가운데·크기 증감·복원·디스플레이 이동 등 18개 창 배치를 제공합니다.
- 키보드 배치는 크기 검사와 고정 대기 없이 요청합니다. 자유 그리기는 지원하지 않는 크기를 경고하고 실제 적용 결과를 유지합니다.
- 설정에서 단축키 기록·해제·중복 차단·기본값 복원을 지원합니다.
- 현재 버전 표시, 자동·수동 업데이트 확인, 새 버전 안내, 확인 후 다운로드·검증·앱 교체·실패 복구를 제공합니다.

## 설치

Apple Silicon, macOS 13 이상을 지원합니다. ZIP과 `.sha256` 파일을 내려받아 SHA-256을 확인하고 압축을 푼 뒤 `SketchFrame.app`을 실행해 주세요. 시스템 설정의 손쉬운 사용 권한을 허용해야 창을 제어할 수 있습니다. Rectangle과 기본 단축키가 겹치므로 한쪽을 종료하거나 키를 변경해 주세요.

현재 빌드는 로컬 인증서로 서명했으며 Apple Developer ID 서명·공증은 포함하지 않습니다. 다른 Mac에서 실행이 차단될 수 있습니다. 업데이트는 기존 앱과 같은 인증서의 식별 규칙을 검증하며 단축키 설정은 유지합니다.

자체 검사 200개, 모의 설치·복구, 실제 서명·ZIP 검사와 설정창 표시를 검증했습니다. 공개 릴리스 사이의 실제 자동 교체는 첫 배포 전이라 수행하지 않았습니다.
