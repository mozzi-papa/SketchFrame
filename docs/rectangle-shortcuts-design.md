# 창 배치와 단축키 설정 구현 계획

사용자가 승인한 범위는 Rectangle 스크린샷의 창 동작 18개와 기존 자유 영역 그리기의 단축키 편집입니다. 기본키는 스크린샷의 Control·Option 기반 설정을 사용하며 가운데 절반과 거의 최대화는 미지정입니다. 자유 드래그 기본 조합은 Command·Shift입니다.

UserDefaults의 shortcutBindings.v1에 동작별 키 코드, 조합키, 해제 여부만 저장합니다. 저장 형식 버전과 동작 식별자는 복원을 위한 구조 정보입니다. 창 배치 기록은 메모리에서만 유지합니다. 이 저장 범위는 명시적으로 승인받았습니다.

- [x] 동작 목록·단축키 모델·검증·설정 저장
- [x] 순수 배치 계산·디스플레이 선택·메모리 복원 기록
- [x] AppKit 두 열 설정 화면·기록 중 전역 실행 중지
- [x] 기존 입력·창 적용 엔진에 키보드 동작과 자유 드래그 설정 통합
- [x] 자체 검사·설정 UI·실제 입력 검증·고정 서명 빌드

계산 기준은 해당 화면의 작업 영역이며 원본 자유 드래그 좌표는 보정하지 않습니다. 거의 최대화는 작업 영역 90%, 크기 증감은 가로·세로 60 렌더링 px씩입니다. 다음·이전 화면은 화면 배치 순서로 순환하고 대상이 하나면 안내합니다. 복원은 사용자의 명시적 명령에서만 수행합니다.

Rectangle의 소스는 분석 참고용으로만 사용하고 계산·모델·설정 UI는 프로젝트에 맞게 작성합니다. 외부 패키지 의존성은 추가하지 않습니다. 실제 테스트 직전 Rectangle 종료는 사용자에게 요청합니다. 기존 QA 수정본과 전용 서명을 유지하며 Git 변경 명령은 별도 승인 없이 실행하지 않습니다.

현재 자체 검사 139개와 고정 서명 빌드가 통과했습니다. 실제 설정 기록·해제·중복 차단·세 조합키 기록·재실행 후 저장 유지·기본값 복원, 창 배치 16개와 두 디스플레이 이동 명령의 완료 응답을 확인했습니다. 디스플레이 이동의 중간 좌표는 별도 검증하지 않았습니다. 자유 드래그 회귀와 입력 연결 복구 검사도 통과했습니다. 연결된 화면과 겹치는 원래 배치는 복원 시 보정하지 않으며 화면이 분리되어 완전히 벗어난 배치만 현재 작업 영역 안으로 보정합니다.

## 사용자 승인 변경: 키보드 크기 검사 생략

키보드 창 배치는 크기 지원 사전 조회·0.4초 대기·결과 조회와 비교·빨간 크기 경고를 생략하고 요청만 전송합니다. 자유 영역 그리기의 검사와 4px 허용 오차는 유지합니다. 복원은 관측하지 않은 결과를 구분하는 메모리 기록으로 최초 기준을 유지합니다. 자체 검사 173개가 통과했습니다. 실제 설정·키보드 배치와 지원하지 않는 크기의 무경고·최초 배치 복원·자유 그리기 회귀 검증이 통과했습니다. 키 입력 대기 총 80ms와 관측을 포함한 검증 응답은 중앙값 88.62ms·최대 90.92ms였습니다. 사용자 단축키 설정은 복구했습니다.
