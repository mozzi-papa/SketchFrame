# 윈도우스케치 MVP 설계

`⌘+⇧+왼쪽 드래그`의 시작점과 끝점으로 만든 원본 사각형을 활성 창에 적용합니다. Swift, AppKit, CoreGraphics 이벤트 탭, ApplicationServices 접근성 API만 사용합니다.

## 입력과 미리보기

입력 콜백은 조합키 확인, 이벤트 소비, 누름 시점의 활성 앱 확보만 담당합니다. 화면 작업은 메인 큐로 전달합니다. 시작점은 고정하며 매 이동마다 두 좌표의 최솟값과 차이로 사각형을 계산합니다. 스냅·최소 크기 확대·작업 영역에 맞춘 보정은 사용하지 않습니다.

미리보기 패널과 글꼴은 입력 연결 전에 준비하고 재사용합니다. 비활성 패널은 마우스 입력과 포커스를 가져가지 않습니다. 시작 화면의 배율로 px를 표시하며 미리보기 표시는 해당 화면에 한정합니다. 표시 영역 밖의 좌표도 배치 요청에서 보정하지 않습니다.

## 대상 조회와 적용

창 조회는 직렬 백그라운드 큐에서 수행합니다. 접근성 조회의 cannotComplete 오류는 한 번 재조회합니다. 이전 세션의 늦은 결과는 무시합니다. 전체 화면 및 변경 불가 창을 거부합니다.

드래그가 끝나면 원본 사각형의 위치·크기를 요청합니다. 앱이 화면에 따라 크기를 제한할 수 있어 이동, 크기 지정, 동일한 요청 위치 지정 순서로 수행합니다. 실제 결과를 0.4초 뒤 읽고 시작 화면의 렌더링 픽셀 기준으로 요청과 비교합니다. 일치하면 배치 완료로 안내하고 다르면 실제 배치와 경고를 반환합니다.

크기나 위치가 다르더라도 실제 배치를 유지합니다. 크기 변경 요청이 거부되어도 요청한 위치를 다시 지정합니다. 최초 이동 요청 자체가 실패하거나 실제 배치를 읽을 수 없으면 오류를 표시합니다. 자동 복원은 수행하지 않습니다.

WindowPlacement는 실제 배치, 크기 불일치 여부와 경고를 전달합니다. 앱이 제공한 최소값으로 요청을 제한한 결과와 실제 크기가 일치할 때만 최소 크기를 원인으로 표시합니다. 나머지는 일반 크기 제한 안내를 사용하며, 위치만 다를 때는 위치 제한으로 구분합니다. 경고에는 시작 화면의 배율로 계산한 요청·실제 px를 두 번째 줄에 표시합니다. 완료된 경고 패널은 실제 창 영역을 나타내며 텍스트를 줄바꿈해 크기가 잘리지 않도록 합니다. 비동기 변경이 더 늦게 발생하는 앱은 관찰 방식 확장이 필요합니다.

## 오류와 상태

오류는 화면에 3초 동안 표시하고 메뉴의 최근 결과에도 남깁니다. 새 드래그·취소·기능 끄기는 이전 오류 숨김 작업을 취소합니다. 이전 타이머가 새 미리보기를 닫지 않도록 합니다.

설정 창, 감지 거리 저장, 다른 창 경계 조회, 최소 크기를 추정해 확대하는 동작은 없습니다. 기존 UserDefaults 값은 읽거나 쓰지 않습니다. 진단은 메모리에서만 유지합니다. 손쉬운 사용 권한은 사용자가 직접 허용합니다.

## 드래그 중 크기 안내

대상 창이 AXMinSize·AXMinimumSize 또는 AXMaxSize·AXMaximumSize를 실제 속성 목록에 노출할 때만 유효한 양의 크기를 읽습니다. 제한을 벗어나면 빨간 경고를 표시하되 좌표·크기·적용 흐름은 바꾸지 않습니다. 나머지 크기는 놓은 뒤 확인한다고 안내하며 지원을 보장하지 않습니다.

실제 적용 후 크기가 요청과 다르면 그 요청 크기를 PID와 접근성 창 객체가 같은 대상에만 기록합니다. 다음 드래그에서 렌더링 픽셀 기준으로 동일한 크기일 때 이전 거부 이력을 안내합니다. 인접하거나 더 작은 크기로 추정 범위를 넓히지 않습니다. 최대 32개 기록을 메모리에 유지하며 요청한 크기가 실제 결과와 일치하면 삭제합니다. 창 내용이 바뀌면 제한도 바뀔 수 있어 경고만 표시하고 재시도를 허용합니다. 위치 불일치나 조회 실패를 크기 거부 기록으로 넣지 않습니다.

## 고정 로컬 서명

빌드는 로그인 키체인의 WindowSketch Local Signing 인증서를 정확히 하나 찾아 공개 인증서 지문으로 서명 대상을 지정합니다. 앱 식별자는 personal.windowsketch를 유지합니다. 인증서가 없거나 모호하면 빌드를 중단하며 임시 서명으로 자동 전환하지 않습니다.

명시적 초기 설정에서만 전용 인증서·개인키를 생성하여 로그인 키체인에 등록하고 현재 사용자의 코드 서명 정책으로 신뢰합니다. 유효한 기존 인증서는 재사용하며 잘못된 상태도 자동 교체하지 않습니다. 개인키 생성·가져오기 파일은 접근을 제한한 임시 폴더에서 처리하고 종료 시 삭제합니다. 인증서 변경 시 기존 접근성 허용은 다시 등록해야 할 수 있습니다.
