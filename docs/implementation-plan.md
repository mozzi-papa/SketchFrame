## Finder 실행 오류 수정

- 증상: Finder에서 앱을 열 수 없다는 알림이 표시되었습니다.
- 시스템 로그: `Unable to load a valid LSApplicationProxy`, 오류 코드 `-10810`이 확인되었습니다.
- 앱 번들, 실행 권한, 서명, 자체 검사는 정상이었지만 macOS 앱 등록 항목에는 `executable:` 경로가 없었습니다.
- 원격지킴이의 번들 구조와 시작 코드를 비교했습니다. 해당 프로젝트는 수정하지 않았습니다.
- 사용자 승인 후 윈도우스케치의 최종 경로에만 `lsregister -f`를 실행하고 `open -g`로 실행했습니다.

- `Source/build.sh` 마지막에 최종 경로 등록을 추가했습니다. 실행 중인 앱 번들은 교체하지 않았습니다.
