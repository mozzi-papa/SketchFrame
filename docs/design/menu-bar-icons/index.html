SketchFrame 메뉴 막대 아이콘 후보 시안 비교

macOS 활성 창 관리자 SketchFrame (Command+Shift+드래그 영역 배치 및 키보드 단축키 반쪽·모서리·최대화 배치) 전용 템플릿 아이콘 4종 비교

SketchFrame 앱 도메인 및 디자인 원칙

  • 핵심 도메인: Command + Shift + 왼쪽 드래그로 사각형 영역을 직접 그려 창의 위치와 크기를 지정하고, 키보드 단축키로 반쪽, 모서리, 최대화, 가운데 배치를 수행합니다.
  • 메뉴 막대 제약: 단색 템플릿(isTemplate = true), 투명 배경, 20×20 viewBox 기준, 실제 16pt / 18pt / 20pt에서 번짐 없는 명확한 시인성을 보장해야 합니다.
  • 디자인 방향: 단순 그리기 펜 도구가 아닌 '창 프레임'과 '영역 배치'가 즉각적으로 인식되는 직관적인 벡터 그래픽을 지향합니다.
