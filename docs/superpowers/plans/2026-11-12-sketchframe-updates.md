# SketchFrame 이름과 업데이트 구현 계획

목표: 기존 앱 식별자와 서명을 유지하며 SketchFrame으로 이름을 바꾸고 GitHub Releases 기반 업데이트 확인·알림·설치를 제공합니다.

승인 범위: 앱 표시 이름과 앱 파일명, 버전 표시, 실행 3초 뒤·매시간 자동 확인과 수동 확인, 새 버전 안내, 사용자 확인 후 다운로드·검증·교체·실패 복구입니다. 원격 저장소는 https://github.com/mozzi-papa/SketchFrame 입니다. 현재 버전 0.1.0·빌드 1을 실제 번들에서 표시합니다. Git 변경과 게시 명령은 별도 승인 전에는 실행하지 않습니다.

상태 저장은 기존 단축키 설정을 유지하고 업데이트 확인 시각·후보·진행 상태는 메모리에만 둡니다. 네트워크 세션은 디스크 캐시·쿠키·자격 증명 저장을 사용하지 않습니다. 다운로드·준비 파일은 임시 폴더에, 교체 백업은 같은 설치 폴더의 제한된 임시 작업 폴더에 두며 완료 후 정리합니다. 복구 실패 시 백업은 보존합니다.

- [x] AppUpdater.swift: 엄격한 버전·릴리스 자산 검증, 자동·수동 비동기 조회, 상태와 알림
- [x] UpdateInstaller.swift: HTTPS ZIP·SHA-256·번들 식별자·버전·현재 서명 식별 규칙 검증, 제한된 압축 해제, 설치 준비·헬퍼 교체와 복구
- [x] main.swift·SettingsWindowController.swift: 버전·업데이트 UI, 확인 후 설치, 종료 시 입력 연결 정리
- [x] Info.plist·build.sh·문서·검사: SketchFrame.app 이름 반영, 기존 바이너리 이름·인증서·번들 식별자 보존
- [x] 자체 검사·모의 HTTP와 설치 복구·고정 서명 빌드·설정창 표시 검증

구현은 이 작업 공간에서 직접 수행하며 사용자 규칙에 따라 TDD·Git 변경 명령은 사용하지 않습니다. 첫 릴리스는 게시 전이라 실제 원격 설치는 모의 응답과 임시 복사본으로 검증합니다. 실제 앱 교체는 사용자가 업데이트를 선택한 경우에만 실행합니다.

검증 결과: 자체 검사 200개, 설치 헬퍼 6개 경로, 실제 서명·ZIP 검증, 다른 코드의 인증서 식별 규칙 유지, 새 이름의 권한·입력 연결 유지, 실제 GitHub 빈 응답과 모의 새 버전 설정창 표시를 확인했습니다. Git 연결·커밋·푸시·첫 릴리스 게시와 실제 원격 앱 교체는 수행하지 않았습니다.
