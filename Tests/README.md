실행 중인 SketchFrame를 정상 종료하고 검사 중 마우스·키보드 조작을 멈춰 주세요. 검증용 창이 활성 상태인지 각 입력 전에 확인하며 바뀌면 중단합니다. 실패 시 검증 앱부터 종료한 뒤 마우스 버튼을 해제합니다. 마지막에 생성한 프로세스만 종료하고 원래 포커스·포인터 위치를 복원합니다. 실행 호스트의 손쉬운 사용 권한이 필요합니다.
