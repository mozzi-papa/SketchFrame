# 실제 입력 검증

최소 크기가 799 × 300 논리 좌표인 검증용 창을 별도 프로세스로 실행합니다. 첫 드래그의 원본 미리보기와 지원 미확인 안내, 요청·실제 크기 경고, 작은 영역의 이동 결과 유지, 같은 크기의 다음 드래그 중 경고, Esc 취소, 네 방향 배치 일치와 가장자리 좌표 보존을 검사합니다.

실행 중인 윈도우스케치를 정상 종료하고 검사 중 마우스·키보드 조작을 멈춰 주세요. 검증용 창이 활성 상태인지 각 입력 전에 확인하며 바뀌면 중단합니다. 실패 시 검증 앱부터 종료한 뒤 마우스 버튼을 해제합니다. 마지막에 생성한 프로세스만 종료하고 원래 포커스·포인터 위치를 복원합니다. 실행 호스트의 손쉬운 사용 권한이 필요합니다.

```sh
xcrun swiftc -swift-version 5 Source/*.swift -o /tmp/WindowSketch-placement-check -target arm64-apple-macos13.0 -framework AppKit -framework ApplicationServices -module-cache-path /tmp/windowsketch-swift-cache -O
xcrun swiftc Tests/NativeFixture.swift -o /tmp/WindowSketch-native-fixture -target arm64-apple-macos13.0 -framework AppKit -module-cache-path /tmp/windowsketch-swift-cache
python3 Tests/native_check.py /tmp/WindowSketch-placement-check /tmp/WindowSketch-native-fixture
```

접근성 트리에서 미리보기 좌표·오류 문구를 읽고 화면 위 패널 존재와 실제 창 배치를 확인합니다. 색상은 그리기 코드에서 확인하며 자동 검사에서 픽셀을 판독하지 않습니다. 사용자 앱 전체와 외부 모니터는 이 검사에 포함하지 않습니다.

## 현재 검사 상태

자체 검사 49개, Python 문법 검사와 최종 번들 빌드·서명 검사가 통과했습니다. 실제 배치 유지, 최소값이 확인된 경우와 미확인 경우의 문구 구분, 요청·실제 px, 위치 제한 구분을 검사했습니다. 실제 마우스 검사는 아직 수행하지 않았습니다. 아래 기록은 해당 버전 당시의 결과입니다.
